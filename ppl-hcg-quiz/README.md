# PPL HCG Quiz

自家用操縦士（滑空機）の学科試験問題を WordPress 上で出題するプラグインです。
バージョン: 1.1.0

## インストール

1. WordPress 管理画面の「プラグイン」→「新規プラグインを追加」→「プラグインのアップロード」から ZIP をアップロードし、有効化します。
2. 既存の固定ページから、クイズ用のカスタム HTML（出題範囲、各ボタン、`question.js` の script タグ）と、クイズ用の style タグを削除します。
3. 代わりにショートコードブロックを追加し、`[ppl_hcg_quiz]` と入力します。
4. 出典、コメント案内、広告、ブログカードは固定ページ側にそのまま残します。
5. 公開前にプレビューし、PC・スマートフォン双方で確認します。キャッシュを使用している場合は更新後に削除します。

FTP を使う場合は `ppl-hcg-quiz` フォルダごと `wp-content/plugins/` に配置し、管理画面で有効化します。
旧 `wp-content/uploads/ppl-hcg-quiz/` は新しいプラグインから参照しません。他のページから参照されていないことを確認するまでは削除不要です。

## ファイル構成

- `ppl-hcg-quiz.php`: ショートコード登録、CSV読込、HTML生成、JS/CSS読み込み。
- `question.js`: 出題範囲の選択、重複除去、シャッフル、問題表示、採点。
- `style.css`: クイズ内部だけの表示設定。
- `question.csv`: 元の問題データ（UTF-8 BOM付き）。
- `fig/`: 元の問題画像。

npm やビルド作業は不要です。問題の追加・訂正は `question.csv` と `fig/` を更新してください。CSVのヘッダー（`Subject ` の末尾の空白を含む）と12列の構成、正解番号1〜4、画像なしを表す `-` は維持してください。CSVの引用符・カンマを含むセルには標準CSV形式を使用できます。

## 出題仕様

- 480問、4科目、24組の年月・科目別問題セット。出題範囲は合計29種類。
- シャッフルでは問題文と正解番号が一致する問題を重複扱いにし、CSV上の最初の問題を採用します。重複除去後に Fisher–Yates 法で並べ替えます。
- 年月・科目別出題は重複除去やシャッフルをせず、CSVの順番で出題します。
- 正解は青、不正解は赤。分からないボタンも不正解として扱い、正解を青で表示します。
- 1問につき採点は1回。回答後に次問へ進み、最終問題の次は同じ出題順の先頭へ戻ります。
- 同一ページに複数ショートコードを配置しても、選択・採点・次問の状態は独立します。
- 問題データと正解はブラウザに渡されます。学習用であり、厳密な試験・不正防止用ではありません。

## v1.1.0 の変更内容

- WordPress プラグイン化。旧固定ページ内の HTML/CSS とアップロード先の固定パスを廃止。
- CSV解析を PHP の `fgetcsv()` に移し、JavaScriptの独自CSV解析と非同期取得を廃止。
- `main()`、`csv_data()`、`csv_array()`、`update_question()`、`shuffle()` を整理。出題範囲を更新する `startQuiz()` と、表示・状態リセットを行う `showQuestion()` に主処理を集約。
- クイズ外のボタンやCSSへの干渉を解消。未使用の進捗バーを削除。
- Fisher–Yates 法に変更し、エラー表示を追加。既存のCSVと画像は無変更。

## 検証
