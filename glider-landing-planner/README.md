# Glider Landing Planner

**対象バージョン：** v0.1.20（WordPressテスト版）

Glider Landing Plannerは、グライダーの離脱地点から着陸地点までの経路を地図上で組み立て、推定飛行時間・高度変化・計算上の高度余裕を比較するツールです。離脱側の経路と着陸側の場周経路を作成すると、その間を5次Bezier曲線で接続します。

**教育・机上検討専用です。実飛行の着陸可否・安全性・障害物クリアランスを判定するものではありません。** 入力した風と機体性能を仮定した計算であり、結果を飛行判断に使用しないでください。

**アプリを開く：** WordPressでGlider Landing Plannerが表示されている公開ページを開いてください。**公開ページの直接URLは、この配布物には設定されていません。** サイト運営者は、公開後にこの行を実際のページへのリンクに置き換えてください。

以下では、標準設定から一つの計画を作ります。すでに編集中の計画がある場合は、先に「JSON保存」でバックアップしてください。

## 1. 新しい飛行計画を始める

1. 画面上部の**「新規」**を押し、確認画面で新規作成を選びます。現在の計画を置き換える操作です。
2. 地図に青い**「離」**（離脱地点）と緑の**「着」**（着陸地点）があることを確認します。
3. 「離」から伸びる**青い約250 mの破線と矢印**を確認します。これは開始機首方位の*方向ガイド*で、直線レグではありません。飛行距離・時間・高度損失には算入されません。「着」へ向かう**緑の破線**は直線ファイナルの進入方向を示します。

この時点では離脱側・着陸側ともレグがなく、接続曲線もありません。「推定総距離」「推定飛行時間」「高度余裕」が「—」になるのは正常な**未設計**状態です。

> 初期地点・進入方向・高度・機体性能は練習用の仮設定です。地図上の「着」は正式な滑走路端や接地点を保証するものではありません。

## 2. 着陸側の場周経路を作る

1. 地図の緑の**「着」**をクリック／タップします。PCでは左側の「着陸地点・ファイナル・場周設定」が操作対象になり、スマートフォンでは下部に編集パネルが開きます。
2. **「左場周プリセット」**を押します。今回は左場周だけを使います。
3. 地図上に緑の着陸側経路と紫の**Bezier接続曲線**が現れることを確認します。着陸側の経路には「＋」も現れます。

プリセットはダウンウィンド、ベース、ファイナルへつながる着陸側レグをまとめて作ります。既存の着陸側レグがある場合は、置換の確認が表示されます。**曲線が表示されても計算上の接続条件を満たすとは限りません。** 成立性は後で「計算上の診断」を確認します。

## 3. 離脱側の経路を作る

1. 地図の青い**「離」**をクリック／タップします。PCでは地図上の追加メニュー、スマートフォンでは下部パネルが開きます。
2. **「＋ 直線」**を選びます。青い方向ガイドが実際の直線レグに変わり、先端に**「＋」**が表示されます。
3. 追加した直線を選択し、編集欄の**「直線距離」**を **300 m** にします。PCでは左サイドバー、スマートフォンでは下部編集パネルで数値を変更します。
4. 青い経路先端の**「＋」**を押し、もう一度**「＋ 直線」**を選びます。
5. 2本目の**「直線距離」**も **300 m** にします。地図に直線が2本つながっていることを確認します。

新しく追加するレグの標準の飛行方式は「進行方向指定」です。方位を編集しない場合は直前の飛行状態を継承します。**地点や直線距離はドラッグで変更しません。** 地点は地図上の指定操作または緯度・経度入力、距離は数値入力で変更します。

## 4. 飛行条件を一つ変更する

1. **「基本条件」**の**「基準対気速度」**を確認します。初期値は **90 km/h** です。
2. **95 km/h** に変更します。地図の接続曲線と計算結果が更新されることを確認します。

「離脱高度」「着陸標高」「風向」「風速」「最大滑空比」「最良滑空速度」も変更できます。沈下率は最大滑空比と最良滑空速度から近似します。ファイナルの速度は直前の着陸側レグの実効速度を継承します（着陸側レグがなければ基準対気速度）。この例では基準対気速度以外は変更しません。

## 5. 計算結果を確認する

1. 地図で**青い離脱側経路、紫の接続曲線、緑の着陸側経路**を確認します。全体が見えない場合は**「全体表示」**を押します。
2. **「高度プロファイル」**を確認します。**青線**は離脱側からBezier接続までの予想高度、**緑線**は着陸側から逆算した必要高度です。横軸は離脱からの推定経過飛行時間、縦軸はMSL高度です。青線と緑線は意図的に別々の系列です。
3. **「推定総距離」「推定飛行時間」「高度余裕」**を確認します。高度余裕は接続境界で比較した、予想高度と必要高度の**計算上の差**です。
4. **「チェックポイント高度」**で各地点の値を確認します。表の「滑空場基準高度」は着陸地点の標高を差し引いた値であり、地面との実際の高さ（AGL）ではありません。
5. **「計算上の診断」**を確認します。「不成立の条件あり」や警告があれば、その内容とBezier接続の最大必要バンク角を確認します。

**高度余裕が正でも安全余裕を意味しません。** 接続が不成立、沈下率が計算不能、またはその他のエラーがある場合は推定総距離・推定飛行時間・高度余裕が**「評価不可」**になります。独立して計算できる部分の経路・高度は表示されます。未完了レグは計算済みの部分を破線で表示し、到達していない正式なチェックポイントは表示しません。不成立のBezier曲線も、領域内の幾何形状が得られれば破線の編集用プレビューを表示します。不成立・未設計の計画でも入力が正常ならJSON保存できます。初期の「—」は未設計、計算中の「評価不可」は必要な条件を評価できない状態であり、意味が異なります。

## 6. 計画を保存・再利用する

1. 上部の**「JSON保存」**を押し、`.glp.json` ファイルを端末へ保存します。JSONは**後から再編集・再計算できる計画データ**です。
2. 保存したファイルを試す場合は**「JSON読込」**から選択し、現在の計画を置き換える確認に同意します。保存内容で計画が復元されます。対応する保存形式はスキーマ1.3のみです。正常なv0.1.17・v0.1.18のJSONも読み込めますが、スキーマ1.0〜1.2は読み込めません。
3. 共有・閲覧用の資料が必要なら、地図の表示範囲を調整したうえで**「PDF印刷」**を押します。別タブの印刷プレビューで地図を確認し、ブラウザの「PDFに保存」などを選びます。

編集中の計画はブラウザのIndexedDBへ自動保存され、次回起動時に復元されることがあります。旧形式の自動保存は復元せず、新規計画を表示します。ただしブラウザのデータ消去や保存失敗に備え、**JSONを別途保存してください**。PDFは結果の閲覧用であり、**JSONの代わりに読み込んで編集することはできません**。

これで、最初の飛行計画の**作成・確認・保存**は完了です。

## 7. 必要になったときの補足

| やりたいこと | 操作・注意 |
|---|---|
| 直線・旋回を追加する | 離脱側・着陸側の「＋」から「＋ 直線」または「＋ 旋回」。サイドバーの各レグ一覧にも追加ボタンがあります。着陸側は**実際の飛行順の先頭側**に追加されます。 |
| 旋回を編集する | レグを選んで**「旋回方向」「バンク角」「入力方式」**を編集。飛行方式に応じて、機首方位または進行方向の**変化量**か**方向そのもの**を指定します。方向は離脱側では旋回後、着陸側では旋回前を指定します。多周旋回の結果は直近の計算角を基準に選択されます。 |
| 飛行方式を変える | 各レグの**「飛行方式」**で「機首方位指定」（機首が向く方向）と「進行方向指定」（地面に対して移動する方向）を切り替えます。進行方向指定でも旋回全体の偏流はなくなりません。進行方向指定・接続・ファイナルでは風速が対気速度未満であることが必要です。対地速度が0.05 m/s未満となる条件も不成立です。 |
| レグ固有の速度を使う | 直線の**「滑空速度」**、旋回の**「旋回速度」**を変更。初期表示の数値は基準対気速度を継承しており、編集すると個別設定になります。空欄に戻すと継承します。 |
| レグを削除・戻す | レグ一覧の「×」または選択したレグの**「このレグを削除」**を使用。上部の**「元に戻す」「やり直す」**も利用できます。着陸側をすべて削除すると接続曲線は消えます。 |
| Bezierを調整する | **「曲線を自動調整」**が基本。必要なら**「地図に制御ハンドルを表示」**をONにし、紫のハンドルをドラッグすると手動調整になります。自動調整は成立を保証しません。 |
| 位置を移動する | **「離脱地点を指定」「着陸地点を指定」**を押してから地図上の位置をクリック／タップするか、座標欄を変更します。地図背景は通常どおり移動できます。計算範囲は着陸地点から50 km以内です。 |
| 風向を確認する | 風向入力は風が吹いてくる真方位。地図のオレンジ色の矢印は風が吹いていく方向を指します。無風時は表示されません。 |
| 高度や方位を読み替える | 高度入力は**MSL**で、単位はft/m切替。滑空場基準高度は着陸標高との差で**AGLではありません**。飛行計算・風向・進入方位は**真方位**で、磁気偏角は補助方位線だけに適用されます。 |
| 印刷時に地図が欠ける | 別タブのポップアップを許可し、地理院タイルの読込後に印刷。必要に応じて背景グラフィックを有効にし、プレビューで地図・出典・高度表示を確認します。 |
